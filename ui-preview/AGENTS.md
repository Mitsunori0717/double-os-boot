# Edge Box のデザイン調整・統合を行う AI へ

このフォルダは、全設定 GUI のデザインを安全に調整するための独立した Windows Forms プレビューです。まず README.md と source.json を読み、cpu/manifest.json と host/manifest.json で編集ファイルと本体の対応範囲を確認してください。Claude は CLAUDE.md も読んでください。

## 編集の範囲

- 利用者向けの表記は「Edge Box」。既存の VM 名、タスク名、ファイル名、型名、設定キーは変更しません。
- 色、フォント、余白、大きさ、配置、描画、読みやすさを調整します。design 対象は README の表と manifest の designFile に列挙されています。
- 入力部品の変数名・名前・データ構造・イベントと保存処理の接続を保ってください。見た目のファイルには画面内の連動イベントも含まれます。そのロジックは変更せず、追加の動作が必要なら統合時に明示して検証してください。
- 本体のスクリプトを読み込んでプレビューを動かすことは禁止です。サンプル提供コードで独立動作させます。実アカウント、パスワード、端末設定、VM、レジストリ、BCD、起動タスクには触れません。
- CPU 画面のアプリ名は `cpu/cpu-ui-theme.ps1` の `$UiAppName` (現在は「CNC SCREEN CORE SPLIT」) で、プレビューも同じ名前を表示します。字体は Eurostile (入っている PC のみ) か同梱の `cpu/fonts/Michroma-Regular.ttf` (SIL OFL) です。統合ツールはフォントを写さないため、フォントを変えるときは本体の `windows-cpu-partition/fonts/` にも同じファイルとライセンスを置きます。本体を統合する際も利用者向け表記を確認してください。既存の識別子はそのまま維持します。
- manifest の baselineHash は作成時の本体の範囲を表します。競合を隠す目的で変更しないでください。マーカーと範囲を勝手に広げないでください。
- `start.cmd` のプレビューはファイル保存で新しいプロセスとして自動で開き直します。全画面と小画面を検証してください。小さい画面の折り返し、長い日本語、無効状態、選択・ホバー・キーボードの見え方も確認します。

## 本体へ統合する時

1. GitHub の最新ソースをクローンし、リポジトリの AGENTS.md を読みます。ZIP 配置の C:\double-os-boot へ直接変更しません。
2. update.ps1 の Repo / Branch とリモートの既定ブランチを確認し、その最新から作業ブランチを作ります。
3. このフォルダの verify.ps1 を実行し、integrate.ps1 -TargetRoot <clone> で取り込み予定を確認します。
4. integrate.ps1 -TargetRoot <clone> -Apply で UI ソースだけを取り込みます。競合なら最新と比較し、動作を保って手動で解決します。統合ツール自体はデザインを実行しません。
5. git diff を確認します。CPU 分離・安全検査・設定保存・VM 操作などの機能は維持し、デザイン以外の差分を混ぜません。
6. 最新のデザインソースを ui-preview にも含めます。取り込み済みで本体とデザインが一致する場合、同じ統合処理は変更なしになります。次のデザイン調整前に基準を更新する必要がある場合は、現在の本体と一致を検証した範囲だけを新しい baselineHash と source.json に記録します。
7. powershell -NoProfile -ExecutionPolicy Bypass -File setup\tests\run-tests.ps1 をクローン側で実行します。実機の再起動、VM 終了、強制電源断を伴うテストは実行しません。停止確認できない VM を残したままホストを終了しません。
8. 通常の commit / push と PR 作成を行います。既定ブランチを再取得し、競合が無ければ確認待ちにせず merge commit で自動マージします。競合を解消したら再検証します。force push は禁止です。

端末固有の設定、ログ、資格情報、取得したツール、生成 EXE、生成 ZIP、検証画像はコミットしません。
