# Windows アプリ整理

**インストール登録の一覧、用途の推定、チェックボックス選択、確認付きMSIアンインストール**をまとめた独立ツールです。Edge BoxのVM・起動・CPU設定には組み込みません。

## はじめに

1. このフォルダー一式をローカルへ展開します（Windows 10/11、Windows PowerShell 5.1、対話デスクトップ）。
2. 最初は `start-demo.cmd` を開いてください。合成データだけを表示し、実PCを読み取らず、アンインストールもできません。
3. 実際に使うときは `start.cmd` を開きます。起動しただけでは一覧取得・削除をしません。
4. 「一覧を読み取る」で、ローカルのインストール登録情報を読みます。Storeアプリは明示チェック時のみ表示します。
5. 行を選ぶと用途の推定・保護理由・未確認事項が表示されます。名前／発行元で検索できます。
6. 対象のチェックボックスを選び「選択内容を確認」。初期状態は全OFFです。最大50件です。
7. 「確認して実行…」で**新しいログ保存先**を指定すると、最新登録と照合して別の日本語確認画面を出します。対象・バージョン・発行元・GUIDをスクロールして確認し、注意事項に同意した場合だけ実行します。
8. 公式Windows Installerが1件ずつ対話表示されます。設定やデータを失う場合があるため、必要なバックアップは先に用意してください。

管理者へ自動昇格しません。権限不足時は処理が失敗し、後続を止めます。自分で管理者として起動する場合も、ユーザーを切り替えると現在ユーザーの登録対象が変わることに注意してください。起動時の `-ExecutionPolicy Bypass` はこのPowerShellプロセスだけの起動引数で、PCの恒久設定を変更しません。コードは未署名です。組織の実行ポリシーを回避・変更する機能はありません。

## 一括処理するもの／しないもの

| 種類 | 扱い |
|---|---|
| 既知の一般アプリ候補で、正しいMSI登録・製品GUID・最新情報の一致を確認できたもの | 明示選択＋別確認後だけ順次処理 |
| EXE型、Store/Appx、portable、登録不明 | 一括削除しない。「Windowsの設定で確認」で公式画面へ |
| OS、更新、共有runtime/framework、ドライバ、マザーボード/GPU/CPU関連 | 保護して一括削除から除外 |
| セキュリティ、ネットワーク、VPN、遠隔接続など | 接続喪失リスクもあるため保護 |
| 用途不明、依存不明の未知アプリ、登録矛盾・不正値 | 要確認として保護 |

保護解除ボタンはありません。手動のWindows設定でも、必要性や業務影響を確かめずに削除しないでください。名前に基づく分類は誤検出・見逃しがあります。**保護されていない＝不要、安全、無害、依存がない、という意味ではありません。** 発行元欄も登録された申告文字列であり署名検証ではありません。

任意の `UninstallString` / `QuietUninstallString` を実行しません。実行するのは固定のWindows `System32\msiexec.exe /x {GUID} /norestart` だけです。cmdやPowerShellの文字列eval、ダウンロード、強制process kill、残骸フォルダー削除、レジストリ掃除、全ユーザーAppx削除、OS部品削除を行いません。MSI内のベンダー独自処理の安全性までは保証しません。

## 用途・通信・「勝手に入った」の証拠

- 用途は**ローカルの名称規則による推定**です。ネットで個別アプリを調べたり、一覧を外部へ送ったりしません。
- 登録が見つかったことと、実ファイルの存在・使用頻度・不要性は別です。
- InstallDateは登録上の値です。MSIでは修復やパッチ適用で更新されることがあり、初回インストール日時の確定証拠ではありません。[Microsoftの登録項目仕様](https://learn.microsoft.com/en-us/windows/win32/msi/uninstall-registry-key)
- インストール実行者・同意の有無・導入経路・通信内容は調べていません。**「勝手に入れられた」「情報流出している」とは判定しません。**
- 通常のアプリ一覧では通信は未計測です。「現在のTCPを観測」を明示操作した場合だけ、下記の単発読取を実行します。継続監視・マルウェア検査・AIによる挙動解析は未実装です。
- portableソフト、別ユーザー、管理製品の一部、全依存グラフは一覧に含まれない場合があります。
- MSIの修復を誘発する `Win32_Product` は一覧取得に使いません。[Microsoftの注意](https://learn.microsoft.com/en-us/troubleshoot/windows-server/admin-development/windows-installer-reconfigured-all-applications)

## 停止・結果・ログ

- 「次の処理から中止」は未開始分だけを止めます。実行中のアンインストーラーを強制終了しません。実行中は本体ウィンドウを閉じられません。
- ユーザー取消、失敗、別インストーラー稼働中、再起動要求、対象情報変更、登録残存・再確認不能で後続を止めます。再試行は一覧再取得と新しい確認からです。
- 自動再起動は行いません。[Microsoftの標準オプション](https://learn.microsoft.com/en-us/windows/win32/msi/standard-installer-command-line-options)
- 終了コード0でも、完全削除・個人データ消去・依存問題なしとは扱いません。登録の消失を再確認しますが、残存ファイルやサービスまでは検証しません。
- ログは選んだローカルの新規 `.jsonl` ファイルです。UTC時刻、段階、対象ID/GUID、終了コード、固定理由コード、例外型/HResultを記録します。生のコマンド文字列や引数は記録しません。既存ログを上書きしません。
- ログにはソフトの識別情報があるので、共有するときは内容を確認してください。ログは改ざん防止署名ではありません。

## 非破壊テスト

```powershell
powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\run-all.ps1
```

一覧/確認/実行をモック化して検査します。UIは合成データの画面を画面外に生成して操作・描画を確認します。実際のインストール一覧の取得、ソフト削除、Windows設定変更は行いません。

実PCの権限、各MSIベンダーの挙動、実際の削除結果、全Windows環境のDPI/表示互換は未検証です。テスト合格を実機削除成功に読み替えません。

開発者用: `package.ps1 -OutputPath C:\任意の既存フォルダー\新しい名前.zip` で、実行に必要な11ファイルだけを新規ZIPへまとめられます。既存ZIPは上書きしません。[検証記録](VALIDATION.md)も参照してください。


## 現在のTCP接続を1回だけ確認

「現在のTCPを観測」を押し、読取内容の確認に同意すると、現在のTCP接続とプロセス情報を一度だけ読みます。観測用に新しいネット通信を発生させず、外部送信・自動保存・バックグラウンド監視はしません。デモでは予約済み例示IPを使う合成データだけです。

- 相手/ローカルIPとport、TCP状態、PID、読み取れたプロセス名・実行パスをローカル表示。
- TCP表とプロセス開始時刻/パスを二重に照合。変化・アクセス拒否・読み取れない対象は「不明」。最大500行、超過時は省略を表示。
- 登録されたInstallLocation配下にプロセスパスがある場合のみ、アプリの**候補**と根拠を表示。共有プロセス、注入コード、依存部品、シンボリックリンク等による完全な帰属は証明しません。
- UDP/QUIC、過去の接続、転送量、通信内容・送信データは対象外。未表示を「通信なし」、接続ありを「情報流出」とは読み替えません。
- IP・パスは個人/機器情報を含む場合があります。スクリーンショット等を共有する前に確認してください。アプリはこの画面の内容をログへ記録しません。
- 一覧未取得でも通信表は読めますが、アプリ候補は不明です。権限や瞬間的な変化により結果は不完全になり得ます。

[Microsoft: Get-NetTCPConnection](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-nettcpconnection)、[Get-Process](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-process)


### 用途辞書の範囲

Chrome / Firefox / Brave、7-Zip、Notepad++、VLC / Audacity / OBS、GIMP / Inkscape / Blender、Zoom / Slack / Discord、Steam / Epic Games、Git / PyCharm / VS Code の19製品について、名称・発行元候補の限定一致から一般的用途と公式出典を表示します。実行時にWeb照会しません。OS・ドライバ・セキュリティ等の保護規則が優先し、開発系には依存確認の保護を追加します。別製品への推測適用や、名称だけによる不要判定はしません。未知製品は「用途不明」のままです。

実体APIの照合は確認直前と各MSI実行直前に行います。アプリ一覧の「MSI候補」はまだ実体確認済みという意味ではありません。製品名・版・発行元・インストールcontext/SIDが一致しない場合は削除しません。確認前の拒否ではログをまだ作成していない場合があり、画面に固定理由コードと例外型を表示します。

実体照合の公式仕様: [MsiGetProductInfoExW](https://learn.microsoft.com/en-us/windows/win32/api/msi/nf-msi-msigetproductinfoexw)（製品情報の照会。Win32_Productの修復照会は使用しません）。

## 判別強化版の使い方と限界

一覧の全行について、登録情報・既知製品の用途・13種類の弱いカテゴリ候補を分けて評価します。「推定の確かさ」は用途候補に関するもので、安全性や削除してよい確率ではありません。19製品の既知ルールだけに限定せず、名称や登録コメントからも候補を表示しますが、不明・複数候補・矛盾はそのまま残します。

- 「判別の根拠を見る」: 概要、根拠の内訳、ファイル・署名、不明時の調査手順を表示します。登録されたパッケージ名、自己申告の発行元・版・説明を確認できます。
- 「実行ファイルを照合」: 利用者が明示指定したローカルEXEだけを読み、SHA-256、製品名、会社名、説明、版、元ファイル名、PE署名領域の構造を表示します。実行しません。自動探索もしません。
- EXE照合は最大128MiB。UNC、ネットワークドライブ、device/ADS、reparse経由を拒否します。読み取り中は書込・削除共有を許可せず、前後のサイズ・時刻と再ハッシュを確認します。キャンセルは読み取り終了後に結果を破棄します。
- 登録情報とEXE情報は自己申告です。一致しても正規品の証明にはなりません。選んだEXEが対象アプリの所有物かも未証明です。版の差は更新等でも起こるため、矛盾を悪性と断定しません。
- 署名領域があっても署名の有効性・証明書主体・失効・発行元の信頼を検証していません。領域がなくてもcatalog署名は否定できません。この版はネット問い合わせを避けるためAuthenticode/WinTrustを呼びません。
- MSIの実体照合は削除承認・各実行直前の既存経路で実施します。判別画面の追加証拠取得では呼びません。判別結果によって削除対象を増やしたり保護を解除したりしません。
- 追加EXE証拠は対象レコードのハッシュと時刻に紐付け、不一致・期限切れを採用しません。再取得で画面の追加証拠を破棄します。自動保存・外部送信はしません。
- 公式URLは固定出典として文字表示するだけです。自動ブラウズ・検索・全一覧アップロードはありません。不明な製品は手元の導入記録とメーカー資料で確認してください。社内名やパスなどを外部検索へ送らないでください。

配布ZIPには14個の起動用ファイルを同梱します。スクリプトは未署名です。実PCでの全DPI表示・実EXE照合・MSI実削除・製品ごとの用途正解率は未検証で、未知の全ソフトを正確に識別する保証はありません。
